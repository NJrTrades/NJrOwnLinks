# Apple-Style Link-in-Bio

A sleek, responsive, Apple-inspired link-in-bio website featuring modern glassmorphism styling, ambient glow effects, interactive card previews for social platforms (Instagram, TikTok, X, GitHub), and a hidden, passphrase-protected link management panel.

## ✨ Features

- **Apple-Inspired Design:** SF Pro typography, frosted glass (`backdrop-filter: blur`), subtle depth shadows, and ambient background glow.
- **Rich Media Cards:**
  - **Instagram:** Displays a 4-photo thumbnail grid.
  - **TikTok:** Interactive video preview cards with live view counts (`▷ 6.8K`).
  - **X (Twitter):** Card layout complete with a verified checkmark badge.
  - **GitHub:** Clean branding link card.
- **Passphrase-Protected Editing:** Hidden link customizer drawer secured via SHA-256 client-side hashing—edit your profile info and social links directly in the browser without revealing credentials.
- **Local Persistence:** Edits saved via `localStorage` so changes persist across page reloads.
- **Zero-Build Overhead:** Runs entirely out of a single standalone HTML file.
